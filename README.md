# Thomso'26 Itinerary-Planner

## Prompt Fest - OpenAI Student Collective IITR

Thomso'26. **Make every minute count.**
Complete, self-contained single-page browser game for the Thomso campus route challenge. It uses the supplied IIT Roorkee campus-plan image as a top-down 2D map background and an animated walker that automatically follows the locked itinerary.

## Play features

- Choose a festival day, add and reorder events, and add breakfast/lunch/dinner directly as itinerary stops.
- Event agendas and itinerary stops show full start and end times, including the next-day marker for overnight events.
- Locking starts an automatic play phase. The walker animates through every selected event and meal in order; the player can pause or change animation speed. Scores and route feedback remain hidden until the recap.
- Each missed meal costs 120 points, 35 health, 20 energy, and adds 24 fatigue. A missed meal can lower health, energy, and performance across the remainder of the day. The recap explains event attendance, headline bonuses, meal penalties, distance, and the day grade. Best scores are stored locally when browser storage is available.
